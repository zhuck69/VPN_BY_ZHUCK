# История изменений

## 1.1.0 — 2026-11-14

- Добавлена подробная русская инструкция по самостоятельной установке официального MTProto-прокси.
- Описаны отдельный TCP-порт, systemd, firewall, генерация секрета, обновление `proxy-multi.conf`, диагностика и отзыв доступа.

## 1.0.0 — 2026-11-14 — первый публичный выпуск

- Добавлен самостоятельный установщик для Ubuntu 22.04/24.04 и Debian 12/13.
- Добавлены VLESS + TCP + REALITY и Hysteria2 с перебросом UDP-портов.
- Генерация UUID, ключей REALITY, паролей и QR-кодов выполняется на VPS пользователя.
- Добавлены резервные копии конфигураций перед повторной установкой.
- Добавлены русские инструкции для Windows, Linux, macOS, HAPP, INCY и совместимых Xray-клиентов.
- Добавлена русская инструкция по безопасным реферальным ссылкам и персональным ссылкам Telegram-прокси.
- Боевые конфигурации ZHUCK VPN, ключи, токены, IP-адреса и подписки в репозиторий не включены.
