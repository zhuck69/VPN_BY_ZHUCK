![Секреты](https://img.shields.io/badge/секреты-на%20VPS-059669)

Безопасный стартовый пакет для развёртывания **собственного** VPN на вашем VPS. Установщик поднимает два независимых транспорта:

- **VLESS + TCP + REALITY** через Xray;
- **Hysteria2 + переброс UDP-портов**.

Пакет не подключается к инфраструктуре ZHUCK VPN, не содержит production-ключей, токенов, UUID, IP-адресов, готовых подписок или общей базы пользователей. Все секреты генерируются непосредственно на вашем сервере.

> [!IMPORTANT]
> Это комплект для самостоятельной установки: «один VPS → один комплект учётных данных». Публичного многопользовательского бота, общей базы подписок и панели выдачи здесь нет. Для нескольких пользователей создавайте отдельные учётные данные/серверы и не раздавайте одну ссылку всем.

## Быстрый старт

1. Создайте чистый VPS с Ubuntu 22.04/24.04 или Debian 12/13.
2. Разрешите SSH и входящие TCP/UDP-порты, перечисленные ниже.
3. Запустите установщик с компьютера, где есть ваш SSH-ключ.
4. Заберите `/root/happ-vpn/subscription.txt` и импортируйте его в HAPP/INCY.
5. Проверьте сервисы и внешний HTTPS-запрос через туннель.

Установщик останавливает ранее запущенные `xray.service`, `hysteria-server.service` и `happ-vpn-udp-hop.service`, перед изменением сохраняет их конфигурации в резервную копию и завершает работу при ошибке проверки Xray или занятом порте 443.

## Требования

- чистый Ubuntu 22.04/24.04 или Debian 12/13;
- root или SSH-пользователь с `sudo` без интерактивного запроса пароля;
- IPv4 или IPv6-адрес, доступный клиентам;
- SSH-ключ на локальном компьютере;
- доступ к `apt`, GitHub Raw и официальным внешним сценариям установки;
- в облачном firewall: TCP 443, UDP 443 и UDP 20000–50000;
- неиспользуемый TCP/UDP 443 на момент установки.

Минимум: 1 vCPU, 1 GB RAM и 10 GB диска. Реальная скорость зависит от CPU, тарифа VPS, MTU и ограничений сети клиента.

## Установка из Windows

Требуется PowerShell 7 (`pwsh`) и доступные `ssh`/`scp` из OpenSSH.

```powershell
pwsh.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\Deploy-To-VPS.ps1 `
  -Server 203.0.113.10 `
  -User root `
  -IdentityFile C:\Users\you\.ssh\id_ed25519
```

Если SSH-имя отличается от публичного адреса VPS:

```powershell
pwsh.exe -NoLogo -NoProfile -ExecutionPolicy Bypass -File .\Deploy-To-VPS.ps1 `
  -Server ssh.example.net `
  -PublicAddress 203.0.113.10 `
  -User root `
  -IdentityFile C:\Users\you\.ssh\id_ed25519
```

Дополнительные параметры:

```text
-RealityTarget  www.microsoft.com:443   Камуфляжная цель REALITY
-RealitySni     www.microsoft.com        SNI для клиентов
```

Не передавайте пароль VPS в командной строке и не сохраняйте его в `.ps1`/`.env`.

## Установка из Linux или macOS

```bash
chmod 700 install.sh
scp -i ~/.ssh/id_ed25519 install.sh root@203.0.113.10:/tmp/zhuck-install.sh
ssh -i ~/.ssh/id_ed25519 root@203.0.113.10 \
  'chmod 700 /tmp/zhuck-install.sh && sudo /tmp/zhuck-install.sh --server-address 203.0.113.10'
```

Или выполните установщик уже на VPS:

```bash
sudo ./install.sh --server-address 203.0.113.10 --profile-name 'My VPN'
```

Параметр `--server-address` обязателен, если VPS не может определить внешний адрес через `api.ipify.org`/`api64.ipify.org`.

## Что создаётся на VPS

| Путь | Назначение |
| --- | --- |
| `/usr/local/etc/xray/config.json` | VLESS + REALITY, владелец `root:<xray-group>`, режим 640 |
| `/etc/hysteria/config.yaml` | Hysteria2 и парольная аутентификация |
| `/etc/hysteria/server.crt`, `server.key` | Самоподписанный сертификат Hysteria2 |
| `/etc/zhuck-vpn/udp-hop.nft` | правило переброса UDP-портов nftables |
| `/etc/systemd/system/happ-vpn-udp-hop.service` | загрузка правила переброса портов |
| `/root/happ-vpn/subscription.txt` | Импортируемая подписка HAPP/INCY |
| `/root/happ-vpn/INSTALL_REPORT.txt` | Ссылки и параметры текущей установки |
| `/root/happ-vpn/*.png` | QR-коды VLESS и Hysteria2 |
| `/root/happ-vpn/backups/<UTC-stamp>/` | Резерв предыдущих конфигураций |

Ссылки и QR-файлы являются секретами доступа. Они выдаются с режимом 600 и не должны попадать в задачи репозитория, чат или публичный репозиторий.

## Импорт в клиенты

### HAPP

1. Откройте **Добавить** → **Импорт из буфера** или отсканируйте QR.
2. Выберите `subscription.txt` как URL/файл подписки.
3. Проверьте, что отображаются VLESS и Hysteria2.
4. Сначала проверьте VLESS, затем Hysteria2 как независимый резерв.

### INCY

1. Скопируйте URL подписки из `INSTALL_REPORT.txt` или содержимое `subscription.txt`.
2. Откройте **Добавить** → **Вставить**.
3. Включите правило прямого доступа к локальным/RU-доменам только если оно вам действительно нужно.

### Другие Xray-клиенты

Поддерживаются v2rayNG, Hiddify и совместимые клиенты. Для VLESS нужны `flow=xtls-rprx-vision`, `security=reality`, `sni`, `pbk` и `sid`; для Hysteria2 — пароль, `pinSHA256`, `obfs=salamander` и диапазон UDP-портов.

## Проверка после установки

На VPS:

```bash
systemctl is-active xray.service hysteria-server.service happ-vpn-udp-hop.service
systemctl --no-pager --full status xray.service hysteria-server.service
ss -lntup | grep -E '(:443|:20000|:50000)'
xray run -test -config /usr/local/etc/xray/config.json
```

С клиента после подключения:

```bash
curl --max-time 15 https://www.cloudflare.com/cdn-cgi/trace
curl --max-time 15 https://api.ipify.org
```

Для HAPP/INCY отдельно проверьте загрузку обычной HTTPS-страницы и обновление подписки. Пинг узла сам по себе не доказывает, что через туннель проходит интернет-трафик.

## Порты и firewall

Разрешите в firewall провайдера и на VPS:

```text
TCP 443       VLESS + REALITY
UDP 443       Hysteria2
UDP 20000-50000  переброс UDP-портов Hysteria2
TCP 22        SSH (ограничьте доверенными адресами)
```

Если используется `ufw`, установщик добавляет правила 443/tcp, 443/udp и UDP 20000:50000 только при уже активном UFW. Правила облачного firewall он не меняет.

## Обновление и откат

Перед каждой повторной установкой создаётся каталог `/root/happ-vpn/backups/<UTC-stamp>/`. Для отката:

```bash
sudo systemctl stop xray.service hysteria-server.service happ-vpn-udp-hop.service
sudo cp -a /root/happ-vpn/backups/<UTC-stamp>/config.json /usr/local/etc/xray/config.json
sudo cp -a /root/happ-vpn/backups/<UTC-stamp>/config.yaml /etc/hysteria/config.yaml
sudo systemctl daemon-reload
sudo systemctl start happ-vpn-udp-hop.service xray.service hysteria-server.service
```

Имена файлов в резервной копии зависят от того, какие конфиги существовали до запуска. Перед восстановлением проверьте `xray run -test` и владельцев/режимы файлов.

## Диагностика

**Сервис не запускается**

```bash
journalctl -u xray.service -n 100 --no-pager
journalctl -u hysteria-server.service -n 100 --no-pager
ss -lntup | grep ':443'
```

Частая причина — другой процесс занял TCP или UDP 443. Остановите его или выберите чистый VPS.

**Подписка импортируется, но трафика нет**

- проверьте TCP/UDP 443 и UDP 20000–50000 в облачном firewall;
- убедитесь, что системные часы VPS синхронизированы (`timedatectl status`);
- попробуйте VLESS и Hysteria2 отдельно;
- сравните `curl` через туннель с обычным подключением;
- не считайте зелёный ping доказательством передачи данных.

**Hysteria2 не подключается**

- проверьте, что UDP 443 не блокируется сетью клиента;
- проверьте весь диапазон переброса UDP-портов;
- импортируйте свежую ссылку из текущего `INSTALL_REPORT.txt`, а не старый QR;
- при UDP-фильтрации используйте VLESS/TCP.

**VLESS/REALITY не подключается**

- проверьте точное совпадение `sni`, `pbk` и `sid`;
- не меняйте публичный адрес после генерации ссылки без повторной установки;
- убедитесь, что клиент поддерживает REALITY и Vision.

**Установка прервана**

Скрипт работает с `set -Eeuo pipefail`, проверяет ОС, параметры, Xray-конфигурацию и состояние systemd. Сохраните вывод команды и содержимое `/root/happ-vpn/backups/`; не публикуйте строки со ссылками или паролями.

## Ограничения

- Пакет не обещает обход любой фильтрации, белых списков или блокировок оператора.
- География выхода определяется IP вашего VPS; название профиля не меняет страну.
- Встроенного балансировщика, Telegram-бота, биллинга, общей подписочной базы и автоматической выдачи для нескольких пользователей нет.
- Бинарники внешних компонентов загружаются во время установки; их доступность и версии зависят от внешних репозиториев.
- Обход блокировок сторонних сервисов, работа банков и мобильных операторов требуют проверки из конкретной сети клиента.

## Безопасность

Не вставляйте в публичный репозиторий `.env`, `INSTALL_REPORT.txt`, приватные ключи, UUID, пароли Hysteria2, QR-коды или готовые VLESS/Hysteria2-ссылки. Для каждого VPS запускайте установщик отдельно и ограничьте SSH доверенными адресами.

Если секрет уже опубликован, считайте его скомпрометированным: удалите его из истории Git, перевыпустите учётные данные повторной установкой и проверьте логи доступа. Сообщения об уязвимостях направляйте приватно по правилам из [`SECURITY.md`](SECURITY.md).

## Участие и дорожная карта

Перед запросом на слияние проверьте синтаксис Bash/PowerShell, отсутствие секретов и корректность `.gitignore`. Не добавляйте реальные конфиги, ссылки, IP-адреса и дампы журналов.

Ближайшие безопасные улучшения:

1. фиксация версий внешних бинарников и проверка подписей;
2. отдельный режим dry-run без изменения systemd;
3. автоматический health-check после установки;
4. тесты импорта подписки в HAPP и INCY без публикации секретов.
