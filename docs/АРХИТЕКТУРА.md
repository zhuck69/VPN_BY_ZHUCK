# Архитектура пакета

## Общая схема

```text
клиент HAPP/INCY
        │
        ├── VLESS + TCP + REALITY ──► Xray ──► Интернет напрямую
        │
        └── Hysteria2 + UDP ───────► Hysteria ─► Интернет напрямую
```

Оба транспорта устанавливаются на одном VPS и используют отдельные учётные данные. Пакет не содержит общего сервера подписок, Telegram-бота, балансировщика, биллинга или промежуточного RU-шлюза.

## Компоненты

| Компонент | Назначение |
| --- | --- |
| `xray.service` | VLESS + TCP + REALITY на TCP 443 |
| `hysteria-server.service` | Hysteria2 на UDP 443 |
| `happ-vpn-udp-hop.service` | Перенаправление UDP 20000–50000 на Hysteria2 |
| `/root/happ-vpn/subscription.txt` | Локальный файл импорта в клиент |
| `/root/happ-vpn/backups/` | Резерв конфигураций перед повторной установкой |

## Что происходит при установке

1. Проверяется ОС, права root, параметры адреса и REALITY.
2. Устанавливаются зависимости и внешние компоненты Xray/Hysteria2.
3. Генерируются новые UUID, ключи REALITY, короткий идентификатор и пароли Hysteria2.
4. Старые конфигурации сохраняются в резервный каталог.
5. Проверяется конфигурация Xray до запуска службы.
6. Включаются службы systemd и правило nftables.
7. Создаются локальная подписка, отчёт и QR-коды.

## Границы доверия

- Приватные ключи и ссылки остаются на VPS с правами `600`.
- Публичный репозиторий содержит только шаблоны и установочную логику.
- Установщик скачивает внешние сценарии по HTTPS во время запуска; перед развёртыванием проверьте их актуальность и репутацию.
- Доступность зависит от IP VPS, firewall, MTU и сети клиента. Название профиля не меняет географию IP.
