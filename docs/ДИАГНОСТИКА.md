# Диагностика по этапам

Проверяйте отказ по цепочке, не меняя сразу несколько параметров.

| Этап | Проверка | Что означает сбой |
| --- | --- | --- |
| DNS | `getent hosts ИМЯ` | Имя не разрешается или DNS недоступен |
| TCP | `nc -vz АДРЕС 443` | Порт закрыт, firewall или маршрут недоступен |
| TLS/REALITY | журнал Xray и точность `sni/pbk/sid` | Несовместимый клиент или устаревшая ссылка |
| UDP | `ss -lunp` и firewall | UDP 443/диапазон hopping заблокирован |
| Служба | `systemctl is-active ...` | Процесс не запущен или завершился |
| Трафик | HTTPS-загрузка через туннель | Рукопожатие прошло, но данные не проходят |

## Минимальный сбор данных

На VPS:

```bash
date -Is
systemctl is-active xray.service hysteria-server.service happ-vpn-udp-hop.service
ss -lntup | grep -E '(:443|:20000|:50000)' || true
journalctl -u xray.service -n 50 --no-pager
journalctl -u hysteria-server.service -n 50 --no-pager
```

На клиенте:

```bash
curl --max-time 15 https://www.cloudflare.com/cdn-cgi/trace
curl --max-time 15 https://api.ipify.org
```

Перед передачей вывода удалите секреты и реальные адреса доступа.
