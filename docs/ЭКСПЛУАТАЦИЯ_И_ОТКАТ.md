# Эксплуатация и откат

## Ежедневная проверка

```bash
systemctl is-active xray.service hysteria-server.service happ-vpn-udp-hop.service
xray run -test -config /usr/local/etc/xray/config.json
ss -lntup | grep -E '(:443|:20000|:50000)'
```

Проверьте HTTPS через подключённый клиент, а не только ping.

## Журналы

```bash
journalctl -u xray.service -n 100 --no-pager
journalctl -u hysteria-server.service -n 100 --no-pager
journalctl -u happ-vpn-udp-hop.service -n 100 --no-pager
```

Перед публикацией вывода удалите ссылки, пароли, UUID и адреса доступа.

## Повторная установка

Повторный запуск останавливает службы и сохраняет существующие конфигурации в `/root/happ-vpn/backups/<UTC-stamp>/`. Не запускайте его на общем сервере без окна обслуживания.

## Откат

1. Выберите резервный каталог.
2. Проверьте, какие файлы в нём действительно есть.
3. Остановите службы.
4. Восстановите только нужные файлы и права доступа.
5. Выполните `xray run -test`.
6. Запустите службы и проверьте HTTPS через клиент.

```bash
sudo systemctl stop xray.service hysteria-server.service happ-vpn-udp-hop.service
sudo cp -a /root/happ-vpn/backups/UTC-ВРЕМЯ/config.json /usr/local/etc/xray/config.json
sudo xray run -test -config /usr/local/etc/xray/config.json
sudo systemctl daemon-reload
sudo systemctl start happ-vpn-udp-hop.service xray.service hysteria-server.service
```

Если резерв содержит старые секреты, считайте их действующими до перевыпуска и не публикуйте.
