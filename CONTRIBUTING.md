# Как вносить изменения

Спасибо за вклад в проект. Репозиторий предназначен для самостоятельного развёртывания VPN на VPS пользователя.

## Перед отправкой изменений

1. Не добавляйте реальные IP-адреса, домены входов, UUID, пароли, приватные ключи, QR-коды, ссылки и дампы журналов.
2. Проверьте, что рабочие файлы из `.gitignore` не попали в коммит.
3. Выполните синтаксические проверки:

   ```bash
   bash -n install.sh
   ```

   ```powershell
   pwsh.exe -NoLogo -NoProfile -Command "[System.Management.Automation.Language.Parser]::ParseFile((Resolve-Path .\Deploy-To-VPS.ps1), [ref]$null, [ref]$null) | Out-Null"
   ```

4. Убедитесь, что README и инструкции соответствуют фактическому поведению установщика.
5. Для изменений установщика опишите, что происходит при ошибке и как выполнить откат.

## Стиль изменений

- Пользовательские сообщения и документация — на русском языке.
- Имена параметров, команд, служб и протоколов оставляйте без перевода.
- Изменение сетевых портов, транспорта или прав доступа сопровождайте обновлением README и раздела диагностики.
- Не добавляйте телеметрию, внешние прокси или отправку секретов без отдельного обоснования.

## Сообщение о проблеме

Укажите ОС VPS, версию клиента, этап отказа и обезличенный вывод команд. Не прикладывайте готовые ссылки, ключи или полные конфигурации.
